# SIGN_BRIDGE
Sign Bridge is a real-time web system that uses a camera and computer vision to recognize hand gestures and facial expressions. It processes these signals with MediaPipe and WebAssembly and converts them into meaningful text or speech, helping sign-language users communicate with people who may not understand sign language.
